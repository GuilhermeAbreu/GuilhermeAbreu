### 👋 Hi, I'm Guilherme

Developer since 2021, working in tech since 2018. I started with PHP, went through support, front-end and back-end, and these days I live in mobile.

- 🚜 At **Drakkar Agricultura de Precisão**, I build the app farmers use out in the field, where a signal is a luxury
- 📡 I enjoy **offline-first** apps: maps, geospatial data, SQLite and syncing when the connection comes back
- 🔌 When the framework isn't enough, I go native and write **Capacitor plugins** in Java, Kotlin and Swift
- 📦 Problems that give me a hard time usually end up as libraries on **npm**
- 📍 Senador Canedo, Brazil
